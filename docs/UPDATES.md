# アプリ内更新の運用方針

- **現在**：NET v0.7.0 でネット越し音声通話が動作済み。
- GitHub Actionsは `assembleDebug` のコンパイル確認のみであり、**自動更新用の固定署名APKではありません**。
- GitHub Releasesへの本番APK公開、SHA-256付き最新バージョン情報、アプリ内「更新を確認」ボタンは今後の実装対象です。

## 正しい更新の流れ

1. Androidの`applicationId`を固定する。
2. 一度だけ生成した署名秘密鍵を、安全な保存先とGitHub Actions Secretsに保管する。**GitHubのコードへ入れない**。
3. 以後すべてのリリースAPKを同じ鍵で署名し、GitHub Releasesへ公開する。
4. アプリはバージョン情報とSHA-256を確認してAPKを取得し、Android標準のインストール確認画面へ誘導する。
5. Androidの安全仕様により、通常のアプリではユーザー操作なしに勝手に更新インストールできない。

## 現在の運用に関する注意

- 既存のv0.7.0 NETはGitHub Actions由来のデバッグ署名です。新しい固定署名アプリへそのまま上書きできるとは限りません。
- 既存端末の録音データ、ペアリング情報を削除しない。
- **現在のAPKが使うサーバー発見URLは従来のmywatch-home2側のまま**。移行時点では通信先を変更していません。
